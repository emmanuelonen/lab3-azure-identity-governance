# Document 01: Activate Microsoft Entra ID P2 Trial

## Overview
Activating a Microsoft Entra ID P2 license tier is a fundamental prerequisite for deploying enterprise Zero Trust governance controls. Standard Entra ID Free lacks advanced security capabilities. P2 features are mandatory for Risk-based Conditional Access, Access Reviews, and Privileged Identity Management (PIM).

## Step-by-Step Activation
1. Navigate to **Microsoft 365 Admin Center** (`admin.cloud.microsoft`) or **Microsoft Entra Admin Center** (`entra.microsoft.com`).
2. Go to **Billing** -> **Your products** (or **Licenses** -> **All products**).
3. Search for **Microsoft Entra ID P2 Trial**.
4. Click **Start free trial** and activate the 30-day evaluation licence (includes 100 licences).
5. Verify status reads **Active**.
