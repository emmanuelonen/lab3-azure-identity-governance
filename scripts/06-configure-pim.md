## Overview
Privileged Identity Management (PIM) provides time-bound, approval-based role activation to mitigate risks associated with permanent administrative access (standing access).

## Governance Notes
PIM eligible role assignments are managed directly via the Microsoft Entra ID Governance portal (`entra.microsoft.com`) or programmatically via Microsoft Graph API PIM endpoints (`/identityGovernance/privilegedAccess`).
